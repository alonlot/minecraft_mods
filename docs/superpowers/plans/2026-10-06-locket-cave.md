# Slytherin's Locket Cave & the Inferi — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add rare coastal Locket caves (Revelio entrance, blood toll, hidden chain and boat, Drink of Despair basin, thirst, Inferi ambush) that each hold one Slytherin's Locket, plus the Inferius mob and the Memory of the Cave vial that maps you to an unlooted cave.

**Architecture:** Pure rule classes in a new `com.hogwartsmagic.locket` package carry every number and decision, and are unit-tested with JUnit 5. Thin Forge classes (blocks, block entities, entities, items, effect) call them. All state is server-side: the basin block entity owns the cave's state and runs the ambush. The client only renders. The cave is a jigsaw worldgen structure (one NBT piece) generated by the existing Python structure script.

**Tech Stack:** Forge 51 / Minecraft 1.21, Java 21, JUnit 5, Python 3 (hand-rolled NBT writer in `build_scripts/generate_biome_structures.py`), Blockbench MCP for the Inferius model.

**Spec:** `docs/superpowers/specs/2026-10-06-locket-cave-design.md`. Read it before any task.

## Global Constraints

- Namespace `hogwartsmagic`. Main registration class `com.hogwartsmagic.ExampleMod` (`J` = `src/main/java/com/hogwartsmagic`, `R` = `src/main/resources`, `RD` = `R/data/hogwartsmagic`).
- New pure logic lives in `J/locket/`, with tests in `src/test/java/com/hogwartsmagic/locket/`. Pure classes import **no** Minecraft classes.
- Server/client safety: never reference `com.hogwartsmagic.client.*` or `net.minecraft.client.*` from common code. Client registration only in `event/ClientModEvents.java`.
- Never use entity event bytes 21, 35 or 63. Use 61, 62, 64, 66 or 67.
- No `switch` on an enum in model or renderer code. Use `if`/`else`.
- Never run gradle while the user's client is running. Ask first if unsure.
- Voldemort's Horcruxes never touch the existing `HorcruxBlock`, `HorcruxData` or `HorcruxSoulEntity`.
- Despair whisper lines are original text, never quotes from the books.
- Run one test class: `./gradlew.bat test --tests "com.hogwartsmagic.locket.<Class>"`. Full data check: `./gradlew.bat runServer` until "Done", then stop.
- Commit after each task (message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`). Pushing needs the user.
- Models: Sonnet implements, Opus reviews, Task 3 (Blockbench) runs on Opus.

**Deviations from the spec, decided while planning (keep them):**
1. The vision overlay uses vanilla effects (Nausea and Darkness for a few seconds) plus chat lines. No new packet.
2. The Concealed Rock glow is client `animateTick` particles while the block is in its revealed state. No packet.
3. "Drink from the lake with an empty hand" can't be detected on the server. A thirsty player drinks from the cave lake by **using a glass bottle on lake water** (the bottle isn't filled) **or by putting their head under the lake water** (`isEyeInFluid(WATER)`).
4. The Inferius grab on land uses the existing **Stunned** effect through `CrowdControl.apply`, so diminishing returns apply. In water it is a per-tick pull.

```java
package com.hogwartsmagic.locket;

/** Numbers for the Inferius. Pure: no Minecraft imports. */
public final class InferiusRules {
    public static final int MAX_HEALTH = 24;
    public static final int GRAB_TICKS = 40;
    public static final int GRAB_COOLDOWN = 100;
    public static final float NON_FIRE_FACTOR = 0.3f;
    public static final float BURNING_FACTOR = 2.0f;
    public static final int FEAR_RADIUS = 6;
    public static final int BLOCK_FEAR_SCAN = 4;
    public static final int IGNITE_ON_FIRE_HIT_SECONDS = 8;
    public static final double WATER_PULL_PER_TICK = 0.05;
    public static final int IDLE_DESPAWN_TICKS = 2400;

    private InferiusRules() {}

    public static float scaleDamage(float amount, boolean fireSource, boolean burning) {
        float scaled = fireSource ? amount : amount * NON_FIRE_FACTOR;
        return burning ? scaled * BURNING_FACTOR : scaled;
    }

    public static boolean isGrabReady(long now, long lastGrab) {
        return now - lastGrab >= GRAB_COOLDOWN;
    }
}
```

```java
package com.hogwartsmagic.entity;

import com.hogwartsmagic.ExampleMod;
import com.hogwartsmagic.locket.InferiusRules;
import com.hogwartsmagic.spell.combat.CrowdControl;
import net.minecraft.core.BlockPos;
import net.minecraft.nbt.CompoundTag;
import net.minecraft.nbt.NbtUtils;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.sounds.SoundEvent;
import net.minecraft.sounds.SoundEvents;
import net.minecraft.tags.DamageTypeTags;
import net.minecraft.tags.FluidTags;
import net.minecraft.util.RandomSource;
import net.minecraft.world.damagesource.DamageSource;
import net.minecraft.world.entity.*;
import net.minecraft.world.entity.ai.attributes.AttributeSupplier;
import net.minecraft.world.entity.ai.attributes.Attributes;
import net.minecraft.world.entity.ai.goal.*;
import net.minecraft.world.entity.ai.goal.target.HurtByTargetGoal;
import net.minecraft.world.entity.ai.goal.target.NearestAttackableTargetGoal;
import net.minecraft.world.entity.monster.Monster;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.item.Items;
import net.minecraft.world.level.Level;
import net.minecraft.world.level.ServerLevelAccessor;
import net.minecraft.world.level.block.Blocks;
import net.minecraft.world.phys.Vec3;
import org.jetbrains.annotations.Nullable;

public class InferiusEntity extends Monster {
    private static final byte EVENT_GRAB = 61;
    private static final byte EVENT_RISE = 62;

    public final AnimationState riseAnimation = new AnimationState();
    public final AnimationState grabAnimation = new AnimationState();
    public final AnimationState recoilAnimation = new AnimationState();

    @Nullable private BlockPos caveBasin;
    private boolean ambush;
    private long lastGrabTick = -1000;
    @Nullable private LivingEntity grabbed;
    private int grabTicksLeft;
    private int idleTicks;

    public InferiusEntity(EntityType<? extends Monster> type, Level level) {
        super(type, level);
    }

    public static AttributeSupplier.Builder createAttributes() {
        return Monster.createMonsterAttributes()
                .add(Attributes.MAX_HEALTH, InferiusRules.MAX_HEALTH)
                .add(Attributes.MOVEMENT_SPEED, 0.2D)
                .add(Attributes.ATTACK_DAMAGE, 4.0D)
                .add(Attributes.KNOCKBACK_RESISTANCE, 0.4D)
                .add(Attributes.FOLLOW_RANGE, 32.0D);
    }

    @Override
    protected void registerGoals() {
        this.goalSelector.addGoal(1, new FloatGoal(this)); // must swim at the surface to climb onto the island
        this.goalSelector.addGoal(2, new PanicGoal(this, 1.3D) {
            @Override protected boolean shouldPanic() { return mob.isOnFire(); }
        });
        this.goalSelector.addGoal(3, new AvoidEntityGoal<>(this, Player.class, InferiusRules.FEAR_RADIUS, 1.0D, 1.25D,
                p -> p instanceof Player pl && InferiusEntity.holdsFire(pl)));
        this.goalSelector.addGoal(4, new MeleeAttackGoal(this, 1.0D, false));
        this.goalSelector.addGoal(6, new WaterAvoidingRandomStrollGoal(this, 0.8D));
        this.goalSelector.addGoal(7, new LookAtPlayerGoal(this, Player.class, 8.0F));
        this.targetSelector.addGoal(1, new HurtByTargetGoal(this));
        this.targetSelector.addGoal(2, new NearestAttackableTargetGoal<>(this, Player.class, true));
    }

    static boolean holdsFire(Player p) {
        return p.getMainHandItem().is(Items.TORCH) || p.getOffhandItem().is(Items.TORCH)
                || p.getMainHandItem().is(Items.FLINT_AND_STEEL) || p.getMainHandItem().is(Items.FIRE_CHARGE)
                || p.getMainHandItem().is(Items.LAVA_BUCKET) || p.getMainHandItem().is(Items.SOUL_TORCH);
    }

    @Override public boolean canBreatheUnderwater() { return true; } // final in 1.21? if so remove and override getAirSupply logic: see note
    @Override protected boolean isSunBurnTick() { return false; }

    @Override
    public boolean hurt(DamageSource source, float amount) {
        boolean fire = source.is(DamageTypeTags.IS_FIRE);
        if (fire && !this.level().isClientSide) this.igniteForSeconds(InferiusRules.IGNITE_ON_FIRE_HIT_SECONDS);
        if (fire && !this.level().isClientSide) this.level().broadcastEntityEvent(this, (byte) 64);
        return super.hurt(source, InferiusRules.scaleDamage(amount, fire, this.isOnFire()));
    }

    @Override
    public boolean doHurtTarget(Entity target) {
        boolean hit = super.doHurtTarget(target);
        if (hit && target instanceof LivingEntity living && !this.level().isClientSide
                && InferiusRules.isGrabReady(this.level().getGameTime(), lastGrabTick)) {
            lastGrabTick = this.level().getGameTime();
            grabbed = living;
            grabTicksLeft = InferiusRules.GRAB_TICKS;
            this.level().broadcastEntityEvent(this, EVENT_GRAB);
            if (!living.isInWater() && !this.isInWater()) {
                CrowdControl.apply(living, ExampleMod.STUNNED.getHolder().get(), InferiusRules.GRAB_TICKS, this);
            }
        }
        return hit;
    }

    @Override
    public void aiStep() {
        super.aiStep();
        if (this.level().isClientSide) return;
        if (grabbed != null && grabTicksLeft-- > 0 && grabbed.isAlive() && (grabbed.isInWater() || this.isInWater())) {
            Vec3 pull = this.position().subtract(grabbed.position()).normalize().scale(InferiusRules.WATER_PULL_PER_TICK);
            grabbed.setDeltaMovement(grabbed.getDeltaMovement().add(pull.x, -InferiusRules.WATER_PULL_PER_TICK, pull.z));
            grabbed.hurtMarked = true;
        } else if (grabTicksLeft <= 0) {
            grabbed = null;
        }
        if (isCaveBound()) {
            idleTicks = this.getTarget() == null ? idleTicks + 1 : 0;
            if (idleTicks > InferiusRules.IDLE_DESPAWN_TICKS && this.isInWater()) this.discard();
        }
    }

    @Override
    public void handleEntityEvent(byte id) {
        if (id == EVENT_GRAB) grabAnimation.start(this.tickCount);
        else if (id == EVENT_RISE) riseAnimation.start(this.tickCount);
        else if (id == 64) recoilAnimation.start(this.tickCount);
        else super.handleEntityEvent(id);
    }

    public void startRise() { this.level().broadcastEntityEvent(this, EVENT_RISE); }
    public void bindToCave(BlockPos basin) { this.caveBasin = basin.immutable(); this.setPersistenceRequired(); }
    @Nullable public BlockPos caveBasin() { return caveBasin; }
    public boolean isCaveBound() { return caveBasin != null; }
    public void setAmbush(boolean ambush) { this.ambush = ambush; }
    public boolean isAmbush() { return ambush; }

    @Override
    protected boolean shouldDropLoot() { return !isCaveBound() && super.shouldDropLoot(); }

    @Override
    public void addAdditionalSaveData(CompoundTag tag) {
        super.addAdditionalSaveData(tag);
        if (caveBasin != null) tag.put("CaveBasin", NbtUtils.writeBlockPos(caveBasin));
        tag.putBoolean("Ambush", ambush);
    }

    @Override
    public void readAdditionalSaveData(CompoundTag tag) {
        super.readAdditionalSaveData(tag);
        caveBasin = NbtUtils.readBlockPos(tag, "CaveBasin").orElse(null);
        ambush = tag.getBoolean("Ambush");
    }

    public static boolean checkInferiusSpawnRules(EntityType<InferiusEntity> type, ServerLevelAccessor level,
                                                  MobSpawnType reason, BlockPos pos, RandomSource random) {
        return Monster.checkMonsterSpawnRules(type, level, reason, pos, random);
    }

    @Override protected SoundEvent getAmbientSound() { return SoundEvents.DROWNED_AMBIENT; }
    @Override protected SoundEvent getHurtSound(DamageSource s) { return SoundEvents.DROWNED_HURT; }
    @Override protected SoundEvent getDeathSound() { return SoundEvents.DROWNED_DEATH; }
}
```

```java
public final class CaveGeometry {
    public static final int ISLAND_RADIUS = 6;
    public static final int ISLAND_DY = 3;
    public static final int CAVE_RADIUS = 34;
    public static final int CAVE_DOWN = 14;
    public static final int CAVE_UP = 26;

    private CaveGeometry() {}

    public static boolean onIsland(int dx, int dy, int dz) {
        return dx * dx + dz * dz <= ISLAND_RADIUS * ISLAND_RADIUS && Math.abs(dy) <= ISLAND_DY;
```

```java
package com.hogwartsmagic.locket;

import java.util.*;

/** Nearest unlooted cave start among candidate chunks. Pure. */
public final class CaveSearch {
    private CaveSearch() {}

    public static long key(long chunkX, long chunkZ) { return chunkX << 32 | (chunkZ & 0xffffffffL); }

    public static Optional<long[]> nearestUnlooted(long px, long pz, List<long[]> candidates, Set<Long> looted) {
        return candidates.stream()
                .filter(c -> !looted.contains(key(c[0], c[1])))
                .min(Comparator.comparingLong(c -> (c[0] - px) * (c[0] - px) + (c[1] - pz) * (c[1] - pz)));
    }
}
```

```java
public static final int REVEAL_RADIUS = 48;
private static final int REVEAL_TICKS = 1200;

/** Reveals Concealed Rock and hidden chains near center. Only walks loaded chunks' block entities. */
public static int reveal(ServerLevel level, Vec3 center, int radius) {
    int count = 0;
    int r2 = radius * radius;
    int minCx = SectionPos.blockToSectionCoord(center.x - radius), maxCx = SectionPos.blockToSectionCoord(center.x + radius);
    int minCz = SectionPos.blockToSectionCoord(center.z - radius), maxCz = SectionPos.blockToSectionCoord(center.z + radius);
    for (int cx = minCx; cx <= maxCx; cx++) for (int cz = minCz; cz <= maxCz; cz++) {
        if (!level.hasChunk(cx, cz)) continue;
        for (BlockEntity be : List.copyOf(level.getChunk(cx, cz).getBlockEntities().values())) {
            if (!(be instanceof CaveMarkerBlockEntity)) continue;
            BlockPos p = be.getBlockPos();
            if (p.distToCenterSqr(center) > r2) continue;
            BlockState s = level.getBlockState(p);
            BooleanProperty prop = s.hasProperty(ConcealedRockBlock.REVEALED) ? ConcealedRockBlock.REVEALED
                    : s.hasProperty(HiddenChainBlock.REVEALED) ? HiddenChainBlock.REVEALED : null;
            if (prop == null || s.getValue(prop)) continue;
            level.setBlock(p, s.setValue(prop, true), Block.UPDATE_ALL);
            level.scheduleTick(p, s.getBlock(), REVEAL_TICKS);
            count++;
        }
    }
    return count;
}
```

```java
/** Flood-fills connected Blood Seal blocks (max 64) and sets OPEN; schedules the reseal on the clicked block. */
static void setArch(Level level, BlockPos start, boolean open) {
    Deque<BlockPos> todo = new ArrayDeque<>(List.of(start));
    Set<BlockPos> seen = new HashSet<>();
    while (!todo.isEmpty() && seen.size() < 64) {
        BlockPos p = todo.pop();
        if (!seen.add(p)) continue;
        BlockState s = level.getBlockState(p);
        if (!(s.getBlock() instanceof BloodSealBlock)) continue;
        level.setBlock(p, s.setValue(OPEN, open), Block.UPDATE_CLIENTS);
        for (Direction d : Direction.values()) todo.push(p.relative(d));
    }
    if (open) level.scheduleTick(start, level.getBlockState(start).getBlock(), 1200);
}

@Override
protected void tick(BlockState state, ServerLevel level, BlockPos pos, RandomSource random) {
    if (!state.getValue(OPEN)) return;
    AABB arch = new AABB(pos).inflate(3);
    boolean someoneInside = level.getEntitiesOfClass(LivingEntity.class, arch,
            e -> level.getBlockState(e.blockPosition()).getBlock() instanceof BloodSealBlock
              || level.getBlockState(e.blockPosition().above()).getBlock() instanceof BloodSealBlock).size() > 0;
    if (someoneInside) { level.scheduleTick(pos, this, 40); return; }
    setArch(level, pos, false);
}
```

```java
public static Optional<BlockPos> findNearestUnlootedCave(ServerLevel level, BlockPos from) {
    var sets = level.registryAccess().registryOrThrow(Registries.STRUCTURE_SET);
    StructureSet set = sets.get(ResourceLocation.fromNamespaceAndPath(ExampleMod.MODID, "locket_cave"));
    if (set == null || !(set.placement() instanceof RandomSpreadStructurePlacement spread)) return Optional.empty();
    Structure cave = level.registryAccess().registryOrThrow(Registries.STRUCTURE).get(LOCKET_CAVE);
    long seed = level.getChunkSource().getGeneratorState().getLevelSeed();
    ChunkPos here = new ChunkPos(from);
    int spacing = spread.spacing();
    int regionX = Math.floorDiv(here.x, spacing), regionZ = Math.floorDiv(here.z, spacing);
    List<long[]> candidates = new ArrayList<>();
    for (int rx = -2; rx <= 2; rx++) for (int rz = -2; rz <= 2; rz++) {
        ChunkPos c = spread.getPotentialStructureChunk(seed, (regionX + rx) * spacing, (regionZ + rz) * spacing);
        candidates.add(new long[]{c.x, c.z});
    }
    Set<Long> looted = new HashSet<>(LootedCaveTracker.get(level.getServer().overworld()).looted());
    for (int tries = 0; tries < 6; tries++) {
        Optional<long[]> best = CaveSearch.nearestUnlooted(here.x, here.z, candidates, looted);
        if (best.isEmpty()) return Optional.empty();
        long[] b = best.get();
        StructureCheckResult r = level.structureManager().checkStructurePresence(new ChunkPos((int) b[0], (int) b[1]), cave, spread, false);
        if (r != StructureCheckResult.START_NOT_PRESENT) return Optional.of(new ChunkPos((int) b[0], (int) b[1]).getMiddleBlockPosition(62));
        looted.add(CaveSearch.key(b[0], b[1])); // not a real cave (biome rejected): skip it
    }
    return Optional.empty();
}
```

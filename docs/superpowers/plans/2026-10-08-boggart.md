# Boggart and Riddikulus

Approved by the user. Build on branch `ccr-f8e6c9c8-akgyo0`. Three implementers run at the same time on disjoint
files. The shared API below is fixed: every agent codes against it, nobody changes it.

## What it is

A **Boggart** is a shape-shifter that hides in dark enclosed places. It has no shape of its own. When a player
comes close, it takes the shape of the mob that has killed that player most often and spreads fear. The charm
**Riddikulus** makes it small and silly; after enough hits it bursts into laughter and smoke.

### Behaviour (server)

- States, synched: `form` (entity type id string, `""` = true form, hidden), `riddikulusHits` (int), `laughTicks` (int).
- HIDDEN: stands still, no AI goals move it, emits a little `LARGE_SMOKE`. It is `isInvisibleTo` nobody (it is a dark
  blob the renderer draws). Every 10 ticks it looks for the nearest living player within `BoggartRules.REVEAL_RADIUS`
  (8) with line of sight. If found: `form = BoggartFears.fearOf(player)`, play `SoundEvents.WARDEN_SONIC_BOOM` at
  0.6 pitch 1.4, burst of `SQUID_INK` particles.
- REVEALED: slow melee monster (speed 0.22, 2.0 damage, 24 HP). Every 40 ticks it pulses fear: every player within
  `BoggartRules.FEAR_RADIUS` (6) gets `MobEffects.DARKNESS` for `BoggartRules.FEAR_DARKNESS_TICKS` (80) and, within
  half that radius, `MobEffects.MOVEMENT_SLOWDOWN` I for 60 ticks. Players whose own fear it wears (the target) also
  hear `SoundEvents.AMBIENT_CAVE` from it.
- No player within 16 blocks for `BoggartRules.HIDE_AFTER_TICKS` (200) → back to HIDDEN (`form = ""`,
  `riddikulusHits = 0`, heal to full).
- `onRiddikulus(rank, caster)`: `riddikulusHits++`, `laughTicks = BoggartRules.LAUGH_TICKS` (60). Remove DARKNESS and
  MOVEMENT_SLOWDOWN from every player within FEAR_RADIUS. Play `SoundEvents.VILLAGER_YES` pitch 1.6 and NOTE
  particles. If `riddikulusHits >= BoggartRules.hitsToBanish(rank)`: `banish(caster)`: discard (not kill, no death
  drops), `POOF` + `NOTE` particles, `SoundEvents.PLAYER_BURP` no; use `SoundEvents.FIREWORK_ROCKET_TWINKLE`; grant
  advancement `hp/riddikulus` to the caster if a ServerPlayer (grant helper copied from
  `BrewAdvancements.grant`, same guard). Mastery hit XP comes from the normal living-hit path; nothing to add.
- While `laughTicks > 0` it cannot attack and moves nowhere (it giggles in place); it still takes damage.
- A Boggart never takes the form of a player: `BoggartFears` maps a player killer to `hogwartsmagic:dementor`.
  With no recorded deaths the form is `hogwartsmagic:acromantula`. A form id that is not a registered type falls
  back to acromantula at reveal time.
- Spawn: `MobCategory.MONSTER`, egg colours 0x1B1426 / 0x6E4A8C. Spawn placement ON_GROUND,
  `MOTION_BLOCKING_NO_LEAVES`, rule: `Monster.checkMonsterSpawnRules` AND sky light at pos == 0 (indoors / under
  cover). Biome spawners: `forbidden_forest.json` monster list weight 6, min 1 max 1; `dementor_fen.json` same.
  Max 1 per 64 blocks: in the rule, refuse if another Boggart is within 48 blocks.

### BoggartFears (server, persisted)

`PlayerPersisted/hogwartsmagic/BoggartFears` is a CompoundTag `{ "<entity type id>": int count }`.
- `record(ServerPlayer victim, DamageSource source)`: the killer is `source.getEntity()`; if null use
  `source.getDirectEntity()`; if still null do nothing. If the killer is a `Player` record key `"player"`.
  Else the key is `EntityType.getKey(type).toString()`. Keep at most 16 keys (drop the smallest when adding a 17th).
- `fearOf(ServerPlayer)`: `BoggartRules.pickForm(Map<String,Integer>)`: the key with the highest count, ties broken by
  natural string order; `"player"` → `"hogwartsmagic:dementor"`; empty → `"hogwartsmagic:acromantula"`.
- Hook: one call in `ModEvents.onLivingDeath` when `event.getEntity() instanceof ServerPlayer`:
  `BoggartFears.record(player, event.getSource())`.

### Riddikulus (spell)

`SpellType.RIDDIKULUS("riddikulus", 0xFF8AD1, 1.0f, 0.54f, 0.82f, ParticleTypes.NOTE, ParticleTypes.HAPPY_VILLAGER, 40, 15, SpellLootRarity.UNCOMMON)`.
Hit effect (`spell/support/RiddikulusSpell.apply(target, caster)`): if `target instanceof RiddikulusTarget t` →
`t.onRiddikulus(DisableSupport.casterRank(caster, SpellType.RIDDIKULUS), caster)`. Otherwise: no damage; the target
gets `MobEffects.GLOWING` 40 ticks and a ring of NOTE particles (a joke, nothing more). Sound mapping: `SPELL_LUMOS`.
Ranks: `BoggartRules.hitsToBanish(rank)`: 1→3, 2→2, 3→2, 4→1; ranks clamp to 1..4.

## Shared API (fixed)

```java
package com.hogwartsmagic.entity.boggart;
public interface RiddikulusTarget { void onRiddikulus(int rank, @Nullable Entity caster); }
```

`com.hogwartsmagic.entity.boggart.BoggartEntity extends Monster implements RiddikulusTarget`, public:
- `String getFormId()` ("" when hidden), `boolean isHidden()`, `int getRiddikulusHits()`, `int getLaughTicks()`,
  `boolean isLaughing()`, `static AttributeSupplier.Builder createAttributes()`,
  `static boolean checkBoggartSpawnRules(EntityType<BoggartEntity>, ServerLevelAccessor, MobSpawnType, BlockPos, RandomSource)`.
- `ModEntities.BOGGART` (`"boggart"`, size 0.6 x 1.95, client tracking 10, update 3).

`com.hogwartsmagic.entity.boggart.BoggartRules` (pure, no Minecraft imports) constants and functions above plus
`float laughScale(int laughTicks, int hits, int needed)`: 1.0 when hits == 0; otherwise
`max(0.35, 1.0 - 0.5 * hits / needed)`, and during the first 10 laugh ticks it wobbles: multiply by
`1.0 + 0.15 * sin(laughTicks * 1.2)`. `boolean shouldHide(int ticksWithoutPlayers)`.

## Client

`client/renderer/BoggartRenderer extends EntityRenderer<BoggartEntity>`: same surrogate trick as
`PetrifiedRemainsRenderer`. Cache the surrogate per form id in a field (recreate on change). Hidden form: surrogate
`minecraft:vex`, drawn with a `BufferSource` that swaps the render type to
`RenderType.entityTranslucent(textures/entity/boggart_shadow.png)` (dark violet smoky 64x64, generated by
`build_scripts/generate_boggart_texture.py`). Revealed: draw the surrogate normally with the boggart's yaw, head
yaw, walk animation speed and hurtTime copied over, scaled by `BoggartRules.laughScale(...)`; while laughing spin the
yaw by `tickCount * 25`. Register in `ClientModEvents` like Grindylow (no model layer needed).

# Portkeys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bindable Portkey (an old boot) and a one-shot Old Portkey that carry the holder, nearby players and tamed pets across the world and between dimensions, with the best-looking effects in the mod.

**Architecture:** Server: `portkey/PortkeyJourneys` is a per-holder state machine (charge, hook, held transit, teleport, landing) ticked from a server tick listener. Destinations load through a self-expiring chunk ticket, never a blocking `getChunk`. The only network traffic is `fx/Fx` kinds. Client: `client/fx/portkey/*` turns those kinds into one timeline: a world-space layer (glow, spirals, runes, implosion, decal), a post-shader layer that wrings the frame into a tunnel and unwinds it at the far end, a first-person boot pose, camera/FOV curves and client-driven sounds. Every number on that timeline lives in the pure `PortkeyTimeline`, so tuning touches one file.

**Tech Stack:** Forge 51 / MC 1.21 / Java 21, official mappings; JUnit 5; GLSL post chain (pattern of `client/fx/moments/DrainPost`); ElevenLabs SFX + ffmpeg; pixkit 16x16 hand grids.

**The tunnel shader** (`portkey.fsh`, one pass over `minecraft:main` at `AFTER_LEVEL`, so the first-person boot draws on top of it).
- World part: take uv about `Centre`. In polar form, `a += Twist * smoothstep(1,0,r)` and `r *= 1 - Pull*(1-r)`. Add an 8-tap radial blur towards the centre, weighted by `Blur`, and R/B taps split by `Chroma` px along the radius. Lift the edges by `Glow * r^2 * glowColour`.
- Tunnel: `z = 0.35/max(r,0.02)`, `u = a/2pi + Spin + 0.08z`, `v = z + Time*2.2`. Three streak bands at N = 24, 48, 96: a cell is lit when `hash(floor(u*N))` > 0.92, stretched along v with `smoothstep` and length growing with z. Colour per streak from `hash2`: core 70%, gold 15%, cyan 9%, rose 3%, violet 3%. The walls are a gradient from `#0B0A1E` to `#1F2A55` with 2-octave value-noise turbulence advected along v. The vanishing point glows `exp(-6r)` core-white. Rim streaks (r > 0.8) are whiter and longer, with a dark vignette at the rim.
- Output: `mix(world, tunnel, Mix)`. As Mix rises the world is wrung hardest, so the frame reads as being twisted into the tunnel.
- Uniforms: `Time, Mix, Twist, Pull, Blur, Chroma, Spin, Centre(vec2), Glow, Seed, InSize, OutSize`.
- Fallback (shader packs on, or the chain failed): the HUD layer draws a dark fill plus 64 rotating gradient streaks from the centre in the same palette (pattern of `TravelFxClient.drawFlooTunnel`). The same fallback also draws over `ReceivingLevelScreen` via `ScreenEvent.Render.Post` while a transit is active, so a cross-dimension loading screen never shows.
